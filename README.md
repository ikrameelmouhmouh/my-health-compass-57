# Alyva

Create a modern mobile health app for iOS and Android.

The app should focus on helping users reach health and fitness goals through nutrition, fasting and exercise.

Start by creating:

Welcome screen

Registration screen

Login screen

User profile setup

During onboarding ask:

• Gender
• Age
• Height
• Current weight
• Goal weight
• Goal (lose weight, maintain, gain)
• Desired weekly weight change
• Activity level
• Workout frequency

Calculate:

• Maintenance calories
• Daily calorie target
• Protein target
• Fat target
• Carbohydrate target

Create a clean and premium design with light mode and dark mode.

Do not create food tracking, fasting or workout tracking yet.
Only build the onboarding flow and user profile system. Design the application architecture so that premium subscriptions can be added later without rebuilding the app.
